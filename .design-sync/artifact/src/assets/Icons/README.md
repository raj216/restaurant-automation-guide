# Icons

Lucide line icons on a 24px grid, 2px stroke, round caps. These files are drawn in terracotta #a74722; in code the `Icon` and `DrawIcon` components take the surrounding text color instead. The kit ships exactly these twelve:

- `arrow-right.svg` — calls to action and next steps.
- `arrow-up-right.svg` — secondary links (TextLink).
- `check.svg` — done checklist rows.
- `check-circle.svg` — a confirmed order; the form's success state.
- `clipboard-check.svg` — menu checked.
- `clock.svg` — time, pending review.
- `hand.svg` — a person decides.
- `lock.svg` — safeguards, no card numbers.
- `map-pin.svg` — location, local availability.
- `phone.svg` — calls.
- `shield-check.svg` — protection, the POS ticket is the source of truth.
- `user.svg` — your team member.
